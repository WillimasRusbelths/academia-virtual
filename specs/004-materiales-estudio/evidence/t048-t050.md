## Reproducción

Usar el harness y las variables privadas ya descritos en
[entorno](implementation-environment.md), sin imprimir secretos. Dentro del runner
aislado, ejecutar generate y build antes de las pruebas HTTP:

```sh
node apps/api/scripts/database.mjs generate
npm run build --workspace @academia/api
cd apps/api
node ../../node_modules/vitest/vitest.mjs run src/modules/materials/domain/transitions.test.ts tests/integration/materials-commands.spec.ts --maxWorkers=2
node ../../node_modules/vitest/vitest.mjs run tests/architecture src/modules/materials tests/integration/materials- --exclude src/modules/materials/domain/transitions.test.ts --exclude tests/integration/materials-commands.spec.ts --maxWorkers=2
```

Desde `apps/web`:

```sh
node ../../node_modules/vitest/vitest.mjs run src/features/materials/material-actions.test.tsx --maxWorkers=2
node ../../node_modules/vitest/vitest.mjs run src --exclude src/features/materials/material-actions.test.tsx --maxWorkers=2
```

La primera ejecución de cada paquete debe fallar hasta implementar T051–T054.
Las exclusiones solo separan este rojo nuevo de la regresión anterior; no se añaden
skip/todo a las suites ni se modifica la configuración de CI.
